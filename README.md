# Pizzeria L’Artisanale — Site officiel (projet)

Site statique responsive, prêt pour GitHub Pages. Aucune installation de Node.js ni de base de données requise.

## Publier avec GitHub Pages

1. Créez un dépôt GitHub, par exemple `pizzeria-lartisanale`.
2. Importez le **contenu** de ce dossier à la racine du dépôt (index.html, styles.css, script.js, assets/).
3. Dans **Settings → Pages**, sous **Build and deployment**, choisissez **Deploy from a branch**, puis `main` et `/(root)`.
4. L’adresse devrait ressembler à `https://votre-pseudo.github.io/pizzeria-lartisanale/`.

## Modifier le site

- `index.html` : textes, sections, liens et coordonnées.
- `styles.css` : couleurs, mise en page et responsive.
- `script.js` : recettes, prix et filtres du menu.
- `assets/logo-artisanale.svg` : logo redessiné en vectoriel à partir de la photo fournie.
- `assets/menu-original.jpg` : photo du menu fournie par le client.
- `assets/pizza-four.webp` : visuel de pizza adapté de la maquette générée.

## À vérifier avant mise en ligne

- La carte et les prix ont été retranscrits depuis une photo à faible définition : relire soigneusement les noms, ingrédients, prix et l'offre promotionnelle.
- Les horaires sont volontairement non indiqués, car les annuaires publics présentent des horaires contradictoires.
- Aucun numéro de téléphone n'est indiqué afin de ne pas attribuer à tort un numéro à la pizzeria.
- L'illustration de carte stylisée ne constitue pas une carte géographique exacte : le bouton dirige vers le lien Google Maps fourni.
- Ce site ne prend pas de commandes ni de paiements en ligne.
